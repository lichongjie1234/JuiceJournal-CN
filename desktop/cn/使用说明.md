# Juice Journal 国服刷图收益试用版

本目录是在 JuiceJournal 源码中新增的独立国服入口，不连接原版服务端，不需要 GGG OAuth。上游：https://github.com/JuiceJournal/JuiceJournal ，源码于 2026-10-15 下载自 master 压缩包。保留原项目许可。

## 启动

只预览或手动核对：双击本目录 index.html，以固定浏览器打开。可导入游戏截图、识别图标、手动填写数量、保存每日收益。请一直使用同一浏览器和同一路径，记录保存在该页面的 localStorage，及时导出 JSON 备份。

桌面截屏和数字 OCR：安装 Node.js 22 或以上，在本目录运行 `npm install`，随后 `npm start`。首次数字 OCR 需要网络下载 Tesseract 英文数字识别模型。未成功下载时仍可手填数量。尚未打包安装器。

## 统计步骤

1. 填写国服赛季作为账本名称并切换。打开普通 12×12 或四倍 24×24 仓库页，将需要统计的通货、材料放在这里。专用通货页布局不规则，本版不支持。
2. 截取主显示器，或导入 PNG/JPG。填写网格行列数，然后依次点击整个网格左上、右下角。这里不应包括仓库边框。
3. 点击一个物品格，填写中文名称、国服每个物品折合多少 D，保存图标模板。每类物品建一次。模板使用实际截图图标，不需要国际服物价。单价为手动维护，尚未连接国服行情。
4. 扫描当前截图，逐格核对物品和数量。未知／空格不会计入收益；发现漏识别，手动选物品。数字看不清时留空，必须填好后才能入账；单个物品无数字时手动填 1。
5. 点击保存刷图前基线。刷图后把掉落放进同一统计页，使用新截图再扫描，核对后结算。需要扣除额外地图或门票成本时填额外投入；已从本页消耗的通货会自动按差额扣除，不要重复扣。
6. 结算后，终点自动成为下一次基线。每日记录按本机日期归组，跨午夜的一次结算归入结算日。切换账本隔离不同赛季。

## 当前完成与限制

- 完成：本地图标模板匹配、相似图标拒识、堆叠数字 OCR 入口、结果校正、前后差值、成本扣除、日汇总、备份导出与恢复。
- 本版是“自动识别 + 人工核对”的试用工具，不是后台全自动拾取统计。没有读取游戏进程或仓库接口。
- 图标相同或相近、发光边框、鼠标悬停、UI 缩放、截图压缩均可能误识别。实际国服截图尚未验证，识别阈值仍需据实调校。
- 仅适合单格可堆叠通货与材料。随机词缀装备、多格装备不估价。
- 仓库买卖、转入转出和价格波动不能自动区别于刷图收入。请固定统计范围并维持相同估值单价。所有结果均为库存估值变化，不等于实际卖出所得。
- 模板或网格变更会清除基线以避免混算，历史结算价格保留。备份恢复也会清除区域与基线。

## 验证

`node --test ../tests/cn-profit.test.js` 检查差额、成本、重复截图零增益、漏填数量拒绝、未知／相似图标拒识和堆叠数字区域隔离。真实游戏截图和桌面数字 OCR 需要另行实测。
