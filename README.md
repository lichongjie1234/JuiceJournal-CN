# JuiceJournal-CN

基于 [JuiceJournal](https://github.com/JuiceJournal/JuiceJournal) 的国服刷图收益试用模块。

## 当前仓库内容

已上传独立国服模块 `desktop/cn` 和测试 `desktop/tests/cn-profit.test.js`。完整上游源码和原版图片资源尚未导入。

## 使用

- 浏览器：打开 `desktop/cn/index.html`，导入仓库截图，建立图标模板并核对物品数量。
- 桌面版：在 `desktop/cn` 运行 `npm install` 和 `npm start`，支持主显示器截图和数字 OCR。
- 说明：[使用说明](desktop/cn/使用说明.md)。

支持仓库前后数量差额、手动国服单价、额外投入扣除、每日汇总和本地备份。真实国服截图及数字 OCR 尚待实测。
