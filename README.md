# POE2 国服背包收益工具 · 0.5.8

Windows 本地桌面工具：从指定游戏窗口截图，统计通货／材料、成本、地图数量和 D 收益。数据保存在本机，不需要账号或部署服务。

## 本机使用

安装目录：`D:\Codex\JuiceJournal-CN`。双击桌面 **POE2 背包收益** 快捷方式。

1. 打开游戏背包，在副屏点击 **扫描背包**。已取消 F8/F9 全局快捷键。
2. 保存前选择：
   - **对比上次背包**：统计上一次有效库存之后的增减；首次扫描只保存基线。
   - **新背包／只存基线**：适用于存仓、交易转出或整理后；本次不计收益，保留此前收益。
   - **空基线／全部计入产出**：将本次扫描中所选统计物品全部计入产出。不要把原有库存误选成新产出。
3. 暂停只暂停计时，仍可扫描、保存和记录地图。无需先手动开启计时才能扫描。
4. **开图 +1 / −1** 只管理图数，成本在本轮概览手动记录；历史已有的关联成本记录仍可核对。
5. 面板显示 D 净收益、D/小时和每图平均净收益。价格或汇率缺失时显示待补价，不将缺价当成零收益。

## 统计清单、纠错与历史

- “统计物品”左右独立搜索、D 价范围筛选和排序；D 价范围收在弹出面板内。
- 左栏支持拖动／单个加入，以及将筛选结果批量加入右栏。点 **保存清单** 后生效。
- 待补价仅在筛选排序时按 0 D 处理；历史结算仍保留缺价状态。
- 选择清单只影响之后的比较，历史收益不重算。未识别、不在所选范围中的格子会提示，保留截图。
- 数量自动读取；低把握数量会标明估算，无法读取时可能按单件估算。双击最近库存变化的数量直接修改，回车或失焦保存、Esc 取消；物品和原单价锁定，合计重算。
- 仅在最终保存背包后记住人工物品识别、数量图样修正和排除规则；临时编辑或放弃扫描不会更新永久记忆。物品身份相同不代表堆叠数量相同，数量变化后重新读取。
- 石板右下角按剩余次数处理；罗马等级独立于堆叠数量。
- 每笔库存变化都有删除入口，先确认再删除。保留比较基线，避免下次重新记入已经删除的收益。
- 支持本轮／已结束历史／全部记录清除，清除前自动备份。识别记忆、清单与设置保留。
- 暂停／继续、结束归档、额外支出、成本修改、置顶、窗口位置、导出／恢复备份。

## 价格和识别的实际边界

价格来源：[poecurrency.top 免费接口与文档](https://poecurrency.top/api.html)，仅供个人非商业使用。启动／小时／手动刷新，离线使用缓存，保留更新时间、赛季、报价单位和异常信息。同一次比较采用同一价格快照；历史记录不随行情刷新改写。

估值使用接口 `sell_avg`，不是保证成交报价。背包买卖、转移、存仓也会影响数量，因此保存前需要选择正确的比较方式。

本机已下载接口涉及的 541 张不同图标（559 个名称），修复了一条失效目录链接；图标匹配仍会遇到近似图、等级和未覆盖物品。不能承诺识别 100% 或任何第三方软件零封号风险。

本工具不读取游戏内存、不注入、不修改游戏文件、不读取封包、不自动操作游戏。只捕获指定窗口并做本地图像计算。当前只验证 2560×1440、主背包 12×5 加扩展背包 6×5 布局；其他分辨率和专用仓库未适配。

## 源码与开发验证

本仓库包含独立国服模块，不含完整 JuiceJournal 上游源码。本次同步为源码更新；不包含安装包、用户截图、账本、模型权重、运行时或下载的游戏图标。

本机入口为 Electron 加载 `desktop/backpack`。运行环境：

```text

runtime/python/                Python 3.12，numpy、Pillow
assets/catalog.json            物品 ID、名称和图标资料
assets/icons/                  公开来源图标缓存
assets/icon-bank.npz            本地图标特征库
cache/eng.traineddata           数字 OCR 资源
validation/backpack-open.png   背包定位参考截图（不公开）
data/backpack/state.json        账本、识别修正、清单和正则方案
```

图标准备脚本支持 `--root` 指定安装目录：先运行 `scripts/build-icon-library.py`，然后在对应安装根目录运行 `scripts/icon_bank.py`。识别不再依赖旧的个人助手或其 187 项分类模型。

```powershell
node --test desktop/tests/*.test.js
# 使用已安装的 Electron：
electron desktop/backpack --ui-test
```

公开测试覆盖账本、暂停扫描、空／存仓基线、价格冻结、成本、地图撤回、删除与纠错、数字误读拒绝、正则范围与长度限制。桌面回归检查使用独立测试数据，覆盖选择器、独立筛选、批量加入、防误删、正则保存及页签隔离。测试通过不等于所有真实物品识别准确率已验收。


## 0.4.0 查询与紧凑操作

- 本轮概览采用紧凑状态条，支持暂停、确认重置计时、开图增减和图数修正。重置保留收入、成本与图数，时薪使用新的有效时长。
- 意外收入与追加成本集中在本轮概览；已移除“玩法与成本”页签，开图不再自动按旧预设计费。
- 待确认页先显示可编辑的物品摘要；同类多格展开后分别修正数量，保存人工识别修正与原因。详细截图核对默认收起。
- 历史支持关键词、快捷日期／自定日期、类型、归档状态、赛季、轮次、收支方向、金额范围、排序与分页；可按日、物品、轮次和类型汇总，导出匹配结果 CSV。
- 查询只计算匹配的条目，使用每笔记录原单价和汇率；待补价不当零，库存成本备忘不重复扣费。


## 0.4.1 记录可信度与简化流程

源码、运行时、离线图标、OCR 模型和正式数据统一放在 `D:\Codex\JuiceJournal-CN`，迁移前原账本备份在 `D:\Codex\backups`。原安装保留，不删除。

正常流程：扫描 → 看上次数量、本次数量、增减和预计金额 → 保存这次增减。存仓后改用“只更新起点”；“现有背包全部计入收入”收在其他方式内，需明确确认。估算不会伪装成人工核实，缺价不当零；保存后有回执和原始截图入口。相同库存重复全部入账被拒绝；空白数字区域不用于数字纠错学习。

开源方案核对（2026-10-17）：[JuiceJournal 上游](https://github.com/JuiceJournal/JuiceJournal)仍将 OCR 描述为实验性回退，API 接入待批准；[Juicy Maps Assistant](https://github.com/blizzardKv/POE-2-Juicy-Maps-Assistant)区分游戏复制文字与不完美的截图数字识别；[poe2stash](https://github.com/micahriggan/poe2stash)从交易网站同步账户物品，未核实适配本项目的国服、离线免登录前提。因此本次不替换架构、不引入新依赖，仅修复现有账本和核对流程。

限制：仅凭前后背包图片不能识别减少的原因；估算数量仍可能错。回归测试通过不代表真实游戏 OCR 已达 100%。


## 0.4.2 扫描性能

- 同一进程内按图片原始字节缓存数字 OCR，最多 256 个结果；数量图片变化后重新识别，不按物品名称或格子位置套用旧数。
- 保留原有两种分割模式、双阈值图片、置信度和冲突检查，不引入新依赖或额外后台识别进程。
- 图标匹配跳过已判定的空格，复用相同裁剪计算；扫描进度最多每半秒广播，减少整份账本反复传送和界面重绘。
- 两张已有真实截图（53／42 个非空格）离线对比，逐格物品、数量、等级与排除结果一致；窗口捕获和实际游戏负载未计入离线计时。


### 0.4.3 扫描核对与纠错管理
- 扫描结论集中显示增减、估算、缺价；数量突增与相同图像名称冲突单独提醒，提示不自动改账。
- 物品减少时，对比保存前再次明确选择实际增减或存仓更新起点。截图不能判断转移原因。
- 设置新增可搜索识别记忆，逐物品确认忘记；自动备份并保留历史。扫描未处理时禁止删除规则。
- 保留按钮扫描、冻结价格、十分钟时薪刷新与原有数量纠错机制。


### 0.4.4 小窗与界面整理
- 右上角“小窗模式”进入迷你面板，可扫描、保存普通扫描、暂停/继续和地图 ±1；减少、未知名称或异常数量需展开核对。
- 小窗独立置顶；不透明度 40%–100%，完整界面恢复 100%。分别保存两种模式的位置与大小，切换不离开当前显示器，重启恢复模式。
- 统一概览、表格、筛选、历史、设置与正则模块的深色配色、字号和间距，无新增运行依赖。
- 时薪沿用十分钟刷新；切换模式不改变数量、价格、计时或收益。


### 0.4.5 撤回、文字对比度与切换性能
- 完整界面和小窗均可撤回最近一次有效操作：扫描保存/放弃、数量修正、收入成本、地图、删记录、归档及统计清单等。恢复库存基线、价格快照和相关识别记忆；撤回扫描保存后回到原草稿。
- 恢复点独立保存在 data/backpack/last-operation.json，只保留一份；支持重启恢复。正在扫描或有未处理草稿时不可撤回，窗口设置和行情刷新不会覆盖恢复点。
- 小窗底部“文字”菜单支持自定义颜色及默认开启的高对比文字。原生透明度仍影响整个窗口，低透明度下文字仍会变淡。
- 窗口设置改走轻量更新通道，延迟合并设置写盘；展开合并原生尺寸变化，避免整页重绘。正式数据只读副本的后台模拟对比约 679ms → <1ms，不包含系统绘制或真实磁盘耗时。
- 修复跨午夜日统计按事件日期归属、手动零数量重复识别、重复扫描绕过赛季验证；失败的记账操作恢复事务前数据。


### 0.4.6 独立紧凑浮窗
- 大窗与小窗可以同时存在，共用一份账本；关闭大窗时，小窗继续显示，点击“大窗”恢复录入界面。小窗扫描后在大窗核对保存，避免两边编辑同一草稿。
- 小窗显示净收益、累计产出和时薪；扫描、暂停、撤回同排。移除图数、每图收益及计时展示，透明度/置顶/文字颜色集中到“设置”。
- 独立保存浮窗位置和自定义尺寸，不再受旧版小窗尺寸上限影响；配置在 D 盘本地数据中。
- 净收益悬停在鼠标附近显示本轮累计物品数量、冻结价格的加权均价和成本，不将当前背包库存混入产出。明细窗口不获取输入焦点。
- 小窗只接收轻量摘要；隐藏的大窗重新打开时再同步完整数据，行情同步成功不再刷屏提示。


### 每次扫描确认（0.5.3）

- 扫描后核对并保存，或放弃当前截图后重新扫描；不再自动暂存至本轮结束。
- 保存会记住物品识别与完全相同截图的确认结果；数量变化重新识别，不套用旧数量。
- 旧版遗留待定截图仍可逐次核对结算，未处理前不新增扫描，避免混合入账。

### 国服材料补货（0.5.0）

- 独立“材料补货”页签，小窗“补货”按钮直达。默认国服入口与赛季采用用户提供的周年庆巅峰挑战链接。
- 第一次在官方市集筛好材料、数量和价格，保存结果页链接与名称；后续一键复用完整链接。支持筛选、编辑、删除确认，以及勾选后逐项打开。
- 通过系统默认浏览器打开腾讯国服 POE2 市集；不采集登录凭据。选择卖家、传送与购买仍在官方页面操作。
- 赛季名称以国服链接为准，可在赛季设置中更新；旧赛季链接打开前确认，不自动改写其条件。
- 常购清单独立于收益记录，随本地 JSON 备份导出和恢复。未接入商品抓取或自动购买。


### 国服低价监控（0.5.1）

1. 在“材料补货”中保存已经限定材料的搜索链接；通用市集首页不能作为材料监控。
2. 点“登录国服市集”，在工具的官方窗口亲自登录。该会话独立于默认浏览器，保存在 D 盘，不导出到账本备份。
3. 在材料行点“监控”，填写低于多少 D 提醒、间隔和秒／分钟单位，再保存启用。默认 2 分钟，最短 60 秒。未设规则时可“立即检查”一次验证查询，不自动启用监控。
4. 软件保持运行时检查；所有材料串行，共享请求间隔与冷却。401／403／验证码会暂停；429 优先遵守服务器等待时间，无等待时间先停 5 分钟，重复触发延长。手动检查及重启不能跳过已保存冷却。浏览器手动搜索也可能占用同一 IP 限额。
5. 按原搜索条件重新查询并读取前 10 条低价结果。按市集该条标价比较，不擅自除堆叠数量；D 直接比较，E 仅在汇率足够新鲜时换算，其他单位跳过。
6. 低于阈值才记录和通知；同一商品相同价格近期去重。系统通知点击后打开补货页，价格记录保留在软件里。可用“测试提醒”检查 Windows 通知和勿扰设置。不会自动购买或传送。

读取到的完整搜索条件会保存为快照，之后重新生成结果，不只依赖旧搜索 ID；赛季或接口规则变化时仍可能需要更新条件。更换链接会暂停旧监控，重命名保留规则。

### 一致性与性能修复（0.5.6）

- 编辑草稿不再训练永久记忆，保存后才学习；取消不会留下本次临时改动。打开基线编辑保持已保存数量。
- 恢复备份保留待确认草稿；原图缺失的草稿不能入账，需保留核对内容后重新扫描。
- 新导出使用 `.poe2backup`，逐个打包引用的截图和裁剪图并校验完整性，恢复时重建本机路径；仍支持旧 JSON。原已缺失的截图会明确提示，不伪造补齐。不会打包市集登录会话。
- 界面只接收展示字段，原图特征和完整价格证据留在原账本；历史未变化时不重复重建查询结果。

### 备份恢复边界修复（0.5.7）

- 导入前校验账本、库存明细、历史价格与合计、成本收入、窗口配置及识别记忆，并预先计算摘要；无效备份不替换正式数据。
- 从文件选择框开始锁定扫描与账本修改，取消或失败后解除；旧版本扫描结果不能写入恢复后的数据。
- 备份和恢复的文件读写、校验及压缩在工作线程运行，主进程仅负责最终应用。后台工作期间市集监控暂停，任务结束后恢复。
- 恢复配置会明确更新已经存在的浮窗位置、尺寸、透明度及置顶；普通再次显示不会覆盖刚拖动的位置。

### 材料补货行内输入（0.5.8）

常购材料的名称、链接和监控条件在对应记录内展开编辑，保存/取消后原地收起。后台搜索条件刷新保留输入，新增入口仍在列表上方。此次复查遗留的异常恢复风险见 [审查报告](REVIEW-2026-10-20.md)。
