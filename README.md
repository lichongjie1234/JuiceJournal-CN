# POE2 国服背包收益工具

Windows 本地桌面工具，通过指定游戏窗口的背包截图记录通货与材料数量变化、刷图成本及计时。当前是需要核对识别结果的开发版本，尚未达到全物品自动识别标准。

## 本次更新

- 新模块 `desktop/backpack`；原 `desktop/cn` 页面保留作旧原型参考。
- F8 捕获指定游戏窗口，主背包 12×5 与扩展背包 6×5；目前只验证 2560×1440 布局。
- 不确定结果进入待确认草稿，不覆盖有效库存。重复图标与等级按组填写名称，数量分别保存；用户可明确选择本组每格一个。
- 石板右下角数字记录为剩余使用次数，不作为堆叠数量。罗马等级与数量分开处理。
- F9 单独记录开图；支持玩法成本预设、额外支出、成本修改、撤销及图数纠正。
- 暂停/继续、结束本轮、每日历史、D/E 显示、置顶与窗口位置保存、备份导出/恢复。
- 免费国服行情同步、本地缓存及离线提示；库存比较冻结价格快照。缺价保留数量，净收益显示待补价。

## 打开与运行

已配置的本机：双击桌面的 **POE2 背包收益** 快捷方式。安装目录为 `D:\JuiceJournal-CN`，工具须保持运行才能监听 F8/F9。

本源码仓库不包含安装包、Electron/Python 运行时、识别模型、图标及用户截图。直接下载仓库不能得到完整安装；尚未发布供其他电脑直接使用的二进制包。

开发入口：Electron 加载 `desktop/backpack`。当前需要以下本地依赖布局：

```text
desktop/cn/node_modules/        Electron 41 / tesseract.js 5
runtime/python/                Python 3.12，包含 numpy / Pillow
assets/item-recognizer/         classes.json、icon-classifier.npz、digit-classifier.npz
cache/eng.traineddata           Tesseract 英语资源
validation/backpack-open.png    经本地验证的背包定位参考截图
data/backpack/                  账本、行情缓存与扫描截图
```

首次 F8 在核对并保存有效背包后，以捕获时间开始本轮。之后 F8 对比上次有效背包；有待确认草稿时，先保存或放弃。黄色项目须核对名称、等级和数量，未知数量不会默认成零或一。石板通过成本事件在本轮一次扣除，库存变化已计费的材料不要再额外计费。

保存按钮会说明尚未核对的格数，并定位第一组待处理物品。核对中的编辑会保存在本地草稿。

## 验证与限制

```powershell
node --test desktop/tests/*.test.js
```

14 项测试覆盖账本、冻结价格、未知数量/缺价、成本防重复、暂停、石板次数、罗马等级及真实 OCR 输出拒绝规则。公开夹具仅包含免费物价响应和 OCR 文本，不包含截图、角色信息或账本。

本地真实截图已验证背包打开/关闭/重新打开、指定窗口捕获及非空格定位。识别覆盖率仍不足，完整物品/等级识别尚未通过准确率验收；单元测试通过不代表自动识别准确。重复分组使用保守图像匹配，不自动复制各格数量。

行情采用接口 `sell_avg` 字段估算，保留计价单位与异常标记；游戏内买卖方向视角尚未完成对照验收，因此不是保证成交的清算报价。历史保留当时价格与汇率。存仓、交易和转入转出也会影响背包统计。

完整上游源码及资源仍未导入，本仓库包含独立国服模块。

价格来源与文档：[poecurrency.top](https://poecurrency.top/api.html)，服务仅供个人非商业使用。
